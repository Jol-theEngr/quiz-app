# The Jol Quiz

The Jol Quiz is a simple, interactive quiz application built with HTML, CSS, and JavaScript. It allows users to test their knowledge by answering trivia questions across different categories and difficulty levels.

## Features

- **Category Selection:** Choose from different trivia categories.
- **Difficulty Levels:** Select Easy, Medium, or Hard.
- **10 Questions:** Each quiz consists of 10 questions.
- **Countdown Timer:** Each question has a 15-second time limit.
- **Instant Feedback:** Correct and incorrect answers are highlighted after selection.
- **Score Tracking:** Keep track of your score as you progress.
- **Results Summary:** View your final score, percentage, and performance message.
- **Best Score:** Your highest score is saved in the browser using localStorage.
- **Responsive Design:** The application adapts to different screen sizes.
- **API Integration:** Questions are retrieved from the Open Trivia Database.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Open Trivia Database API
- Browser localStorage

## How to Use

1. Open The Jol Quiz application.
2. Select your preferred quiz category.
3. Choose a difficulty level.
4. Click **Start Quiz**.
5. Answer each question before the timer runs out.
6. Click **Next** to proceed to the next question.
7. View your final score and performance summary.
8. Click **Play Again** to start another quiz.

## Getting Started

To run the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/Jol-theEngr/quiz-app.git
   ```

2. Navigate to the project folder:

   ```bash
   cd quiz-app
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## API

This project uses the [Open Trivia Database API](https://opentdb.com/) to retrieve quiz questions and categories.
